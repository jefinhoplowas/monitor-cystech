Configurações dos avisos

Como funciona. Os dados das usinas são lidos das plataformas de monitoramento dos fabricantes e gravados aqui a cada sincronização. Durante a janela solar, uma usina entra em alerta quando para de comunicar, gera quase nada para a potência instalada, rende bem abaixo das outras no mesmo horário, tem equipamento offline ou tem alarme no portal. Os botões de WhatsApp abrem a conversa com a mensagem pronta; o envio é feito por você.
